# Clifford Probetso — Portfolio

A personal portfolio site built with React and Vite.

## Development

```bash
npm install
npm run dev
```

Open the URL printed by Vite (usually `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

The deployable output is generated in `dist/`.

## Project structure

- `src/main.jsx` — React entry point
- `src/App.jsx` — page composition and gallery state
- `src/components/` — page sections and UI components
- `src/data/` — projects, skills, and contact content
- `src/hooks/` — reveal, scroll spy, and media query hooks
- `src/styles.css` — site styles
- `public/` — images, screenshots, and favicon
